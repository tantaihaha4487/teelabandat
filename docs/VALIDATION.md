# ผลการตรวจรับ

ตรวจเมื่อ 17 ตุลาคม 2026 ใน `/home/mashiro/Development/JavaScript/dssi-exam` ใช้ production build และ Astro preview ที่ `http://localhost:4322/`

## ตรวจด้วยคำสั่ง

- `bun run check`: 0 errors, 0 warnings, 0 hints
- `bun run build`: สร้างเว็บ static 34 หน้า รวมการตรวจเนื้อหาก่อน build
- `bun run validate`: 3 หมวด 27 บทเรียน 109 ตัวอย่างพร้อมคำอธิบาย 1 คลังโจทย์
- เทียบต้นฉบับครบ 130 บล็อกโค้ด ผลลัพธ์ และแผนภาพ ตรวจโจทย์เดิม 73 ข้อ โค้ด ตัวเลือก ลำดับตัวเลือก และดัชนีคำตอบตรงต้นฉบับ
- `bun run check:routes`: ลิงก์ภายในและ anchor ผ่านครบ 34 หน้า
- `bun run check:extension`: เพิ่มหมวดและบทเรียนชั่วคราว สร้างหน้าหมวด หน้าบทเรียน และรายการบนหน้าแรกโดยไม่แก้แม่แบบหรือ navigation จากนั้นนำข้อมูลชั่วคราวออกและ build คืนเรียบร้อย

## ตรวจในเบราว์เซอร์

- เดินคำอธิบายโค้ดไปข้างหน้า ย้อนกลับ และคัดลอกโค้ด
- ตอบถูกและผิด ตรวจเหตุผลและคะแนน ล็อกตัวเลือกหลังตรวจคำตอบ
- เปลี่ยนหัวข้อ: ยกเลิกแล้วคำตอบเดิมยังอยู่ ยืนยันแล้วเริ่มหัวข้อใหม่ และกลับไปทุกหัวข้อได้
- รีเฟรชแล้วคำตอบและคะแนนหายตามข้อกำหนด ไม่มีการบันทึกความคืบหน้า
- เปิดโจทย์ 44 แล้วเห็นบริบท input `twenty`
- ค้นภาษาไทย ชื่อคำสั่ง และชื่อตัวแปร `is_student` ซึ่งพบเฉพาะบทพื้นฐานที่มีตัวอย่างนั้น ล้างคำค้นกลับสู่สถานะเริ่มต้น
- ตรวจมือถือ viewport 390×844 และหน้าแรกจอใหญ่ 1440×1000 บทเรียนและแบบฝึกไม่ทำให้หน้าล้นแนวนอน เมนูบทเรียนมือถือพับไว้ตั้งแต่ HTML เริ่มต้น
- ใช้ Tab บนหน้าค้นหา โฟกัสไปปุ่มล้างคำค้นและมี outline 3px
- บทความ โค้ด และรายการคำอธิบายทั้งหมดอยู่ใน HTML ที่สร้างจาก server ส่วนการเดินทีละขั้นและแบบฝึกใช้ Vue

## ขอบเขต

ตรวจตัวอย่างทั้ง 109 ชุดและแก้ความหมายของคำอธิบาย เช่น การปัดเศษ การตัดช่องว่าง และค่าเริ่มต้นของคำสั่ง Git ไม่ได้รันตัวอย่าง Python/Git ทุกชุด บางชุดตั้งใจผิดหรือเป็นส่วนหนึ่งของโปรแกรมและคงสถานะนั้นไว้ ไม่ได้คลิกตอบทุกข้อทั้ง 73 ข้อ แต่ตรวจข้อมูลเดิมครบด้วยตัวตรวจอัตโนมัติ

ตรวจโค้ด CSS ของ reduced motion แล้ว การเคลื่อนไหวใช้ transform/opacity และไม่รอ animation เพื่อเปลี่ยนสถานะ ยังไม่ได้สลับค่าลดการเคลื่อนไหวของระบบจริงหรือทำ screen reader audit และ cross-browser audit เต็มรูปแบบ
