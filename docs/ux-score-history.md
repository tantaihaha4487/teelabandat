# ประวัติคะแนน UX/UI

## เกณฑ์

ให้คะแนน 1–10 จากการทบทวนแบบไม่เห็นคะแนนเดิม แล้วคำนวณค่าเฉลี่ยถ่วงน้ำหนัก: ลำดับชั้นและอัตลักษณ์ 20%, ความชัดเจนในการอ่านและโครงสร้างข้อมูล 25%, ความชัดเจนของการโต้ตอบและผลตอบกลับ 20%, การปรับตามหน้าจอ 20%, และการเข้าถึงกับสถานะที่ครอบคลุม 15% คะแนนจะถือว่ายืนยันได้เมื่อผู้ทบทวนอิสระทั้งสามคนประเมินเวอร์ชันเดียวกันจากหลักฐานปัจจุบัน

## สรุป

| รอบ | คะแนน | ส่วนต่างจากรอบก่อน | สถานะ |
| --- | ---: | ---: | --- |
| Baseline | 7.70/10 | — | ยืนยันโดยผู้ทบทวนอิสระสามคน |
| Iteration 1 | ยังไม่มีคะแนน | ยังสรุปไม่ได้ | แก้และตรวจการทำงานแล้ว แต่ผู้ทบทวนอิสระเปิดหน้าเว็บไม่ได้ |
| Iteration 2 | ยังไม่มีคะแนน | ยังสรุปไม่ได้ | แก้และตรวจการทำงานแล้ว แต่ผู้ทบทวนอิสระยังเข้าถึงหลักฐานไม่ได้ |

คะแนนที่ยืนยันได้สูงสุดยังเป็น **7.70/10** จาก Baseline; Iteration 1 และ 2 ยังไม่มีหลักฐานพอให้ประกาศคะแนนใหม่ ค่าเปลี่ยนแปลงที่ยืนยันได้จึงเท่ากับ **0.00** ไม่ใช่การยืนยันว่าคุณภาพไม่เปลี่ยน

| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| A | 8.5 | 8.0 | 7.3 | 8.4 | 7.0 | 7.89 |
| B | 8.7 | 8.2 | 7.6 | 8.2 | 6.7 | 7.96 |
| C | 8.4 | 7.8 | 6.0 | 7.4 | 6.2 | 7.24 |
| เฉลี่ย | 8.53 | 8.00 | 6.97 | 8.00 | 6.63 | **7.70** |

หลักฐานภาพของ Baseline ครอบคลุมหน้าแรกเดสก์ท็อปและบทเรียนกับแบบฝึกบนมือถือที่ความกว้างประมาณ 390px; ผู้ทบทวนไม่ได้ตรวจทุกเส้นทางหรือทุกความกว้างด้วยภาพ

### Iteration 1 — candidate ที่ยังไม่ให้คะแนน

**ปัญหาที่พบ:** ปุ่ม “เริ่มใหม่” แสดงก่อนมีคำตอบและไม่ทำให้สถานะเปลี่ยนเมื่อกด; ระยะด้านบนของหน้าแบบฝึกบนมือถือทำให้โจทย์เริ่มช้ากว่าที่ควร

**การแก้:** ซ่อนปุ่มเริ่มใหม่จนกว่าจะมีคำตอบที่ล้างได้ใน `src/components/interactive/QuizRunner.vue`; ลด padding ของบทนำแบบฝึกที่หน้าจอไม่เกิน 760px ใน `src/styles/global.css`.

**หลักฐานตรวจ:** `bun run check` ผ่านโดยไม่มีข้อผิดพลาด คำเตือน หรือ hints; `bun run validate` ยืนยัน 27 บทเรียนและโจทย์เดิมครบ 73 ข้อ; `bun run build` สร้าง 34 หน้า; `bun run check:routes` ผ่านครบ 34 หน้า HTML. ที่ความกว้าง 320, 390, 820 และ 1440px เส้นทางหน้าแรก บทเรียน ค้นหา และแบบฝึกไม่มี document-level horizontal overflow. บนแบบฝึกมือถือ คำถามเริ่มสูงขึ้น 90px; ปุ่มเริ่มใหม่ไม่ปรากฏเมื่อยังไม่มีคำตอบ, ยกเลิกกล่องยืนยันแล้วยังคงคำตอบเดิม, และยืนยันแล้วล้างคำตอบได้.

**คะแนนและการตัดสินใจ:** ผู้ทบทวนอิสระทั้งสามคนพยายามเปิด preview แต่เซสชันของพวกเขาไม่มี browser; จึงไม่ได้ตรวจภาพหรือให้คะแนน Iteration 1 คงเป็น candidate ที่ยังไม่ยืนยัน ส่วน Baseline ยังคงเป็นเวอร์ชันที่มีคะแนนยืนยันสูงสุด สำเนาโค้ด Baseline อยู่ใน `.work/ux-checkpoints/baseline/`.

### Iteration 2 — candidate ที่ยังไม่ให้คะแนน

**ปัญหาที่พบ:** หน้าค้นหาที่ยังไม่มีคำค้นมีเนื้อหาสั้น ทำให้ footer อยู่กลาง viewport มือถือและเหลือพื้นที่ว่างขนาดใหญ่ด้านล่าง

**การแก้:** จัด body เป็นคอลัมน์สูงอย่างน้อยเท่าหน้าจอ ให้ main ขยายรับพื้นที่ว่าง และกำหนดความกว้างเต็มพื้นที่ให้ header/footer เพื่อคงเส้นขอบและแนวจัดวางเดิม

**หลักฐานตรวจ:** `bun run check` ผ่านโดยไม่มีข้อผิดพลาด คำเตือน หรือ hints; `bun run validate` ยืนยัน 27 บทเรียนและโจทย์ 73 ข้อ; `bun run build` สร้าง 34 หน้า; `bun run check:routes` ผ่านครบ 34 หน้า HTML. ตรวจ 4 เส้นทางที่ความกว้าง 320/390/820/1440px แล้ว document ไม่ล้นแนวนอน; footer ของหน้าค้นหาสั้นตรงกับขอบล่าง viewport และ footer ของหน้าบทเรียนกับแบบฝึกยังอยู่หลังเนื้อหาที่เลื่อนดูได้. การค้นคำว่า “ตัวแปร” ยังแสดง 15 ผลลัพธ์.

**คะแนนและการตัดสินใจ:** ผู้ทบทวนอิสระทั้งสามคนยังเปิด preview ไม่ได้ และภาพจาก browser ของผู้ดำเนินงานไม่ปรากฏในบริบทของผู้ทบทวน จึงไม่มี blind re-score สำหรับ Iteration 2. Candidate นี้ยังไม่ใช่ Best Verified; คะแนนที่ยืนยันได้สูงสุดคงเป็น Baseline 7.70/10.

## โอกาสและข้อจำกัดที่เหลือ

- ตัวเลือกแรกของโจทย์ยาวยังอยู่ต่ำกว่าขอบจอแรกบนมือถือ 390px หลังย่อช่องว่างแล้ว; อย่าตัดบริบทโจทย์เพื่อดันตัวเลือกขึ้นโดยไม่ตรวจผลต่อความเข้าใจ
- ยังไม่มี screen-reader audit, การตรวจด้วยการตั้งค่าลดการเคลื่อนไหวจริง หรือ cross-browser audit เต็มรูปแบบ
- ต้องทำ blind re-score บน candidate ที่ความกว้าง 320/390/820/1440px ก่อนตัดสินใจเลื่อนเป็น Best Verified

สอง candidate iterations มีการตรวจใน browser โดยผู้ดำเนินงานแล้ว แต่ยังไม่มี independent re-score เพราะผู้ตรวจเข้าถึง browser preview และภาพปัจจุบันไม่ได้ ลูปยังไม่เสร็จ; การเปลี่ยนแปลงยังไม่ถูกเลื่อนเป็น Best Verified และคะแนนที่ดีขึ้นยังไม่ถูกอ้าง
