# ทีละบรรทัด

เว็บเรียน Python และ Git ภาษาไทย พร้อมคำอธิบายโค้ดและแบบฝึก Python

```sh
bun install
bun run dev
```

เปิด URL ที่คำสั่งแสดงใน terminal

```sh
bun run validate
bun run check
bun run build
bun run check:routes
```

เนื้อหาอยู่ใน `src/content` คลังโจทย์อยู่ใน `src/data` อ่าน [CONTENT.md](CONTENT.md) เพื่อเพิ่มหมวดหรือบทเรียน และ [DESIGN.md](DESIGN.md) สำหรับแนวทางออกแบบ

ใช้ Astro สร้าง HTML, Vue สำหรับส่วนโต้ตอบ และฟอนต์ที่เก็บกับโปรเจกต์ ไม่มีบัญชีหรือการบันทึกความคืบหน้า คำตอบแบบฝึกอยู่ในหน่วยความจำและหายเมื่อรีเฟรช

ต้นฉบับ Python101, Git101 และ Wayo quiz ไม่ถูกแก้ไข ดูที่มาและการเรียบเรียงผ่าน Claude + Humanizer ใน `docs/editorial`
