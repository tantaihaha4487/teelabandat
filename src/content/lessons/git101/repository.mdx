repository คือที่ที่ Git เก็บประวัติทั้งหมดของโปรเจกต์ มีสองวิธีให้เริ่ม เลือกใช้วิธีเดียวตามสถานการณ์:

| สถานการณ์ | คำสั่ง |
| --- | --- |
| เริ่มโปรเจกต์ใหม่ในโฟลเดอร์ของเราเอง | `git init` |
| ทำงานต่อจากโปรเจกต์ที่มีอยู่แล้วบน GitHub | `git clone` |

ตัวอย่างด้านล่างรวมคำสั่งไว้ที่เดียวให้เห็นภาพรวม ในงานจริงไม่ต้องรันทั้งหมดต่อกัน ถ้าใช้ `git clone` ให้ `cd` เข้าโฟลเดอร์ที่ clone มาก่อน แล้วจึงรัน `git status`

## ทำงานอย่างไร

- `git init` สร้าง repository ใหม่ในโฟลเดอร์ปัจจุบัน (Git จะสร้างโฟลเดอร์ซ่อนชื่อ `.git` ไว้เก็บประวัติ)
- `git clone` คัดลอก repository ที่มีอยู่แล้วมาไว้ในเครื่อง ได้ทั้งไฟล์และประวัติทั้งหมด
- `git status` บอกว่าไฟล์ไหนถูกแก้ ไฟล์ไหนยังไม่ถูกติดตาม และไฟล์ไหนพร้อม commit

## จุดที่มือใหม่พลาดบ่อย

- รัน `git init` ผิดโฟลเดอร์ เช่น ในโฟลเดอร์ผู้ใช้ทั้งโฟลเดอร์
- แก้ไฟล์แล้วลืมดูสถานะ
- คิดว่า clone กับการดาวน์โหลด zip เหมือนกัน แต่ clone ได้ประวัติมาด้วยและส่งงานกลับได้

## ฝึกทำ

1. สร้างโฟลเดอร์ทดลองแล้วรัน `git init`
2. สร้างไฟล์หนึ่งไฟล์แล้วดู `git status`

## สรุป

ตอนนี้คุณสร้าง repository และเช็กสถานะไฟล์ได้แล้ว บทถัดไปจะเลือกไฟล์และสร้าง commit แรก
