Repository คือที่ที่ Git เก็บประวัติทั้งหมดของโปรเจกต์ คุณสร้าง repository ใหม่เองก็ได้ หรือจะ clone ของคนอื่นมาเริ่มทำงานต่อก็ได้ ทั้งสองวิธีนี้เป็นทางเลือกที่ใช้แทนกัน ไม่ใช่ขั้นตอนที่ต้องทำต่อกัน

ตัวอย่างด้านล่างนี้นำทั้งสองคำสั่งมาแสดงไว้ในที่เดียวเพื่อให้เห็นภาพรวม แต่ในการใช้งานจริงคุณจะเลือกใช้อย่างใดอย่างหนึ่งตามสถานการณ์ และถ้าใช้ git clone ให้ cd เข้าไปในโฟลเดอร์ repo ที่ clone มาก่อน แล้วจึงรัน git status

## ทำงานอย่างไร

- `git init` สร้าง repository ใหม่ในโฟลเดอร์ปัจจุบัน
- `git clone` คัดลอก repository ที่มีอยู่แล้วมาไว้ในเครื่อง
- `git status` บอกว่าไฟล์ไหนถูกแก้หรือพร้อม commit

## จุดที่มือใหม่พลาดบ่อย

- รัน `git init` ในโฟลเดอร์ผิดที่
- แก้ไฟล์แล้วลืมดูสถานะ
- คิดว่า clone กับ download คืออย่างเดียวกัน

## ฝึกทำ

1. สร้างโฟลเดอร์ทดลองและรัน `git init`
2. สร้างไฟล์หนึ่งไฟล์แล้วดู `git status`

## สรุป

ตอนนี้คุณสร้าง repository และตรวจสอบสถานะไฟล์ได้แล้ว บทถัดไปจะสอนการคัดเลือกไฟล์และสร้าง commit แรก
