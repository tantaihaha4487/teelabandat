ยินดีต้อนรับสู่ Git101 คอร์สนี้ออกแบบมาสำหรับคนที่เพิ่งเริ่มใช้ Git และอยากเข้าใจ workflow จริงแบบไม่ต้องจำคำสั่งแบบท่องจำ เป้าหมายคือให้คุณใช้ Git กับงานของตัวเองได้อย่างมั่นใจ

## วิธีเรียน

1. อ่านคำอธิบายก่อนรันคำสั่ง
2. พิมพ์คำสั่งเองอย่างน้อยหนึ่งรอบ
3. ลองแก้ไฟล์แล้วดู `git status`
4. ฝึก commit สั้น ๆ หลายครั้ง
5. ถ้าเจอ conflict ให้อ่านสถานะก่อนแก้

## เริ่มจากตรงไหน

- [Setup](/learn/git101/setup/) ติดตั้ง Git และตั้งค่าเริ่มต้น
- [Basics](/learn/git101/basics/) เรียนคำศัพท์สำคัญของ Git
- [Roadmap](/learn/git101/roadmap/) ดูภาพรวมการเรียน 4 สัปดาห์
- [Projects](/learn/git101/projects/) ฝึกใช้ Git กับสถานการณ์จริง

## สิ่งที่จะได้เรียน

- ติดตั้ง Git และตั้งค่า user name, email
- เข้าใจ repository, working tree, staging area, commit, branch
- ใช้คำสั่ง add, commit, status, log, diff, branch, merge, remote
- ย้อนการเปลี่ยนแปลงได้อย่างปลอดภัย
- ทำงานร่วมกับ GitHub แบบพื้นฐาน
