คอร์สนี้สำหรับคนที่เพิ่งเริ่มใช้ Git เราจะเรียนจากงานที่ทำจริงในแต่ละวัน ไม่ต้องท่องคำสั่ง เรียนจบแล้วคุณควรใช้ Git กับงานของตัวเองได้โดยไม่กลัวทำไฟล์หาย

Git คือโปรแกรมที่จดประวัติการแก้ไฟล์ในโปรเจกต์ เหมือนกด save แบบมีชื่อกำกับ ย้อนกลับไปดูหรือกู้คืนเวอร์ชันเก่าได้ทุกเมื่อ

## วิธีเรียน

1. อ่านคำอธิบายก่อนรันคำสั่ง
2. พิมพ์คำสั่งเองอย่างน้อยหนึ่งรอบ
3. ลองแก้ไฟล์แล้วดูผลจาก `git status`
4. ฝึก commit ครั้งละน้อย ๆ แต่บ่อย ๆ
5. ถ้าเจอ conflict ให้อ่านสถานะก่อนลงมือแก้

## สิ่งที่จะได้เรียน

- ติดตั้ง Git และตั้งค่า user name กับ email
- เข้าใจ repository, working tree, staging area, commit และ branch
- ใช้คำสั่ง add, commit, status, log, diff, branch, merge และ remote
- ย้อนการเปลี่ยนแปลงอย่างปลอดภัย
- ทำงานร่วมกับ GitHub ขั้นพื้นฐาน
