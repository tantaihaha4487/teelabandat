แผนนี้แบ่ง Git ออกเป็นสี่สัปดาห์ ฝึกทีละขั้นโดยไม่ต้องรีบ

สามคำสั่งนี้ใช้ได้ทุกสัปดาห์เวลาอยากรู้ว่าตอนนี้อยู่ตรงไหน `git status` บอกสถานะไฟล์ `git log --oneline --decorate --graph --all` วาดประวัติทุก branch เป็นเส้นกราฟ commit ละบรรทัด และ `git branch --show-current` บอกชื่อ branch ที่อยู่ตอนนี้

## สัปดาห์ที่ 1

- ติดตั้ง Git และตั้งค่าเริ่มต้น
- พื้นฐาน repository, staging และ commit

## สัปดาห์ที่ 2

- ดูประวัติด้วย `git log` และ `git diff`
- ฝึกสร้างและสลับ branch

## สัปดาห์ที่ 3

- ฝึก merge และแก้ conflict
- remote, push, pull และ fetch

## สัปดาห์ที่ 4

- ฝึกย้อนงานอย่างปลอดภัย
- ทำโปรเจกต์จริงและลองเปิด pull request
