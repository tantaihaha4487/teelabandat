ถ้าคุณอยากเรียน Git แบบไม่รีบ นี่คือแผนที่ช่วยให้เห็นภาพรวมและฝึกทีละขั้น

## สัปดาห์ที่ 1

- ติดตั้ง Git และตั้งค่าเริ่มต้น
- เรียนพื้นฐาน repository, staging, และ commit

## สัปดาห์ที่ 2

- ดู history ด้วย `git log` และ `git diff`
- ฝึก branch และการสลับ branch

## สัปดาห์ที่ 3

- ฝึก merge และแก้ conflict
- เรียน remote, push, pull, และ fetch

## สัปดาห์ที่ 4

- ฝึก undo อย่างปลอดภัย
- ทำโปรเจกต์จริงและลอง pull request
