## โปรเจกต์แนะนำ

- **Notes repo**: สร้าง repository สำหรับจดโน้ตการเรียน
- **Branch practice**: แยก branch ตามหัวข้อแล้ว merge กลับ
- **Remote practice**: เชื่อม repository กับ GitHub และทดลอง push/pull

## สิ่งที่ควรฝึกในแต่ละโปรเจกต์

1. สร้าง repository ใหม่
2. ทำ commit อย่างน้อย 3 ครั้ง
3. สร้าง branch ใหม่ 1 branch
4. ทดลอง merge หรือ revert อย่างน้อย 1 ครั้ง

## สรุป

ยิ่งฝึกโปรเจกต์ซ้ำ ๆ คำสั่ง Git ก็จะกลายเป็นนิสัยในการทำงานจริงของคุณ
