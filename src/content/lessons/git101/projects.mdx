วิธีจำคำสั่ง Git ได้ดีที่สุดคือใช้กับงานของตัวเองบ่อย ๆ ไม่ต้องเริ่มจากงานใหญ่ เริ่มจากงานเล็กแล้วทำซ้ำจนคล่อง

ทุกโปรเจกต์เริ่มแบบเดียวกัน: สร้าง repository เพิ่มไฟล์แรก แล้ว commit

## โปรเจกต์แนะนำ

| โปรเจกต์ | ทำอะไร |
| --- | --- |
| Notes repo | สร้าง repository ไว้จดโน้ตการเรียน |
| Branch practice | แยก branch ตามหัวข้อ แล้ว merge กลับ |
| Remote practice | เชื่อม repository กับ GitHub แล้วลอง push/pull |

## สิ่งที่ควรฝึกในแต่ละโปรเจกต์

1. สร้าง repository ใหม่
2. ทำ commit อย่างน้อย 3 ครั้ง
3. สร้าง branch ใหม่ 1 branch
4. ลอง merge หรือ revert อย่างน้อย 1 ครั้ง

## สรุป

ทำโปรเจกต์ซ้ำไปเรื่อย ๆ แล้ว คำสั่ง Git จะกลายเป็นนิสัยตอนทำงานจริงโดยไม่ต้องนึก
