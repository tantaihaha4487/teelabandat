Git จดประวัติการเปลี่ยนแปลงของไฟล์ บทนี้สั้น ๆ แค่ตรวจว่าเครื่องมี Git แล้ว และบอก Git ว่าเราเป็นใคร

## สิ่งที่ต้องมี

- Terminal (macOS/Linux) หรือ PowerShell (Windows)
- Git ที่ติดตั้งแล้ว
- โฟลเดอร์สำหรับเก็บงานฝึก

## คำสั่งเริ่มต้น

บรรทัดแรกเช็กว่าติดตั้ง Git แล้วหรือยัง ถ้าขึ้นเลขเวอร์ชันแปลว่าพร้อม สองบรรทัดถัดมาตั้งชื่อและอีเมลที่จะติดไปกับทุก commit คนอื่นจะได้รู้ว่าใครแก้อะไร เปลี่ยน `"Your Name"` และ `"you@example.com"` เป็นของคุณเอง

ค่าที่ตั้งด้วย `--global` ใช้กับทุก repository ในเครื่องนี้ ถ้าใช้อีเมลต่างกันในแต่ละโปรเจกต์ ให้เช็กอีเมลที่ใช้อยู่ด้วย `git config user.email` ก่อน commit

## จุดที่มือใหม่พลาดบ่อย

- ลืมตั้งชื่อและอีเมล commit จึงไม่มีข้อมูลผู้เขียนที่ถูกต้อง
- พิมพ์คำสั่งผิดเพราะยังไม่คุ้นกับ terminal
- สับสนระหว่าง Git กับ GitHub: Git คือโปรแกรมในเครื่องเรา ส่วน GitHub คือเว็บที่เก็บ repository ไว้ออนไลน์

## ฝึกทำ

1. เช็กเวอร์ชัน Git ของเครื่อง
2. ตั้งค่า name และ email ของตัวเอง
3. เปิด terminal ใหม่แล้วลอง `git config --global user.name` ถ้าขึ้นชื่อที่ตั้งไว้ แปลว่าตั้งค่าสำเร็จ

## สรุป

เครื่องของคุณพร้อมใช้ Git แล้ว บทถัดไปจะอธิบายศัพท์ที่ต้องเจอบ่อย เช่น repository, staging area และ commit
