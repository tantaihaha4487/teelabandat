Git คือเครื่องมือเก็บประวัติการเปลี่ยนแปลงของไฟล์ ก่อนไปบทถัดไป ให้ตรวจสอบก่อนว่าเครื่องของคุณมี Git พร้อมใช้งานแล้ว

## สิ่งที่ต้องมี

- Terminal หรือ PowerShell
- Git ติดตั้งแล้ว
- โฟลเดอร์สำหรับเก็บงานฝึก

## คำสั่งเริ่มต้น

ค่าที่ตั้งด้วย `--global` มีผลกับทุก repository บนเครื่องนี้ ถ้าใช้อีเมลต่างกันในแต่ละโปรเจกต์ ควรตรวจอีเมลปัจจุบันด้วย `git config user.email` ก่อน commit

## จุดที่มือใหม่พลาดบ่อย

- ลืมตั้งค่า name/email ทำให้ commit ไม่สวย
- พิมพ์คำสั่งผิดเพราะยังไม่คุ้น terminal
- สับสนระหว่าง Git กับ GitHub

## ฝึกทำ

1. เช็กเวอร์ชัน Git ของเครื่อง
2. ตั้งค่า name และ email ของตัวเอง
3. เปิด terminal ใหม่แล้วลอง `git config --global user.name`

## สรุป

ตอนนี้เครื่องของคุณพร้อมใช้งาน Git แล้ว บทถัดไปจะพาไปรู้จักศัพท์สำคัญอย่าง repository, staging area, และ commit
