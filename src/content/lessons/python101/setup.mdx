## Python คืออะไร

Python เป็นภาษาโปรแกรมที่อ่านง่าย ใช้ได้หลายงาน ตั้งแต่เว็บ งานอัตโนมัติ การวิเคราะห์ข้อมูล AI ไปจนถึงสคริปต์เล็ก ๆ ที่ช่วยประหยัดเวลา มือใหม่มักเริ่มที่ Python เพราะ syntax (รูปแบบการเขียน) ไม่ซับซ้อน และมีผู้ใช้เยอะ เวลาติดปัญหาจึงหาคำตอบได้ง่าย

## ติดตั้ง Python

1. ไปที่ `https://www.python.org/downloads/`
2. ดาวน์โหลด Python เวอร์ชัน 3.12 หรือใหม่กว่า

## REPL คืออะไร

REPL คือโหมดลองคำสั่ง Python ทีละบรรทัด พิมพ์แล้วเห็นผลทันทีโดยไม่ต้องสร้างไฟล์ เหมาะกับการลองอะไรสั้น ๆ เปิดด้วย:

<CodeExample example={examples['python101-setup-05']} />
บรรทัดที่เราพิมพ์ใน REPL จะมีเครื่องหมาย `>>>` นำหน้า

ใน REPL พิมพ์ `1 + 2` แล้วจะเห็นผลลัพธ์ทันที แต่ในไฟล์ `.py` ผลลัพธ์จะไม่ขึ้นหน้าจอเอง ต้องใช้ `print()` เสมอ

พิมพ์ `exit()` เมื่อต้องการออกจาก REPL

## ข้อผิดพลาดที่พบบ่อย

- ติดตั้งแล้วแต่ใช้ `python` ไม่ได้: ตรวจ PATH หรือลองใช้ `python3`
- รันผิด folder: ใช้ `pwd` (macOS/Linux) หรือ `dir` (Windows) ดูว่าตอนนี้อยู่ที่ไหน และมีไฟล์ที่จะรันอยู่หรือเปล่า
- ตั้งชื่อไฟล์ว่า `python.py`: ชื่อนี้ชนกับชื่อภาษา ให้ใช้ชื่ออื่นอย่าง `hello.py`
