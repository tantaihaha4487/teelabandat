## Python คืออะไร

Python เป็นภาษาโปรแกรมที่อ่านง่าย ใช้ได้หลายงาน เช่น เว็บ ระบบอัตโนมัติ วิเคราะห์ข้อมูล AI และสคริปต์เล็ก ๆ สำหรับผู้เริ่มต้น Python มีจุดเด่นคือ syntax ไม่ซับซ้อนและมีชุมชนผู้ใช้งานขนาดใหญ่ที่ช่วยตอบคำถามได้

## ข้อผิดพลาดที่พบบ่อย

- ติดตั้งแล้วแต่ใช้ `python` ไม่ได้: ตรวจสอบ PATH หรือใช้ `python3` แทน
- รันผิด folder: ใช้ `pwd` หรือ `dir` เพื่อตรวจว่าคุณอยู่ที่ไหน
- ชื่อไฟล์เป็น `python.py`: อย่าตั้งชื่อชนกับชื่อภาษา ให้ใช้ `hello.py` แทน

## แบบฝึกหัด

1. สร้างไฟล์ชื่อ `intro.py` ใน folder ที่กำลังเรียน
