`from ... import ...` ดึงมาแค่สิ่งที่ต้องการ แล้วเรียกชื่อนั้นได้ตรง ๆ ไม่ต้องมีชื่อ module นำหน้า

## Built-in modules ที่ควรรู้

module เหล่านี้ติดมากับ Python ไม่ต้องติดตั้งเพิ่ม

- `random` สุ่มค่า
- `math` คณิตศาสตร์
- `datetime` วันเวลา
- `os` ทำงานกับระบบไฟล์และ environment

## สร้าง module เอง
