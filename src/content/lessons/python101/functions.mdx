## สร้าง function

ใช้ `def` ตามด้วยชื่อ วงเล็บ และ `:` บรรทัดที่ย่อหน้าเข้าไปคือคำสั่งข้างใน การสร้าง function ยังไม่ทำให้มันทำงาน ต้องเรียกชื่อพร้อมวงเล็บอย่าง `greet()` ก่อน

## พารามิเตอร์ (Parameters)

parameter คือช่องรับค่าที่ function รอไว้ ค่าที่ส่งเข้าไปตอนเรียกจะถูกใส่ในช่องนั้น function เดียวจึงทำงานกับข้อมูลที่ต่างกันได้

<CodeExample example={examples['python101-functions-03']} />
ผลลัพธ์: `สวัสดี Mali`

## ค่าที่ส่งกลับ (Return value)

`return` ส่งค่าออกมาจาก function เพื่อให้โค้ดส่วนอื่นเอาไปเก็บ แสดง หรือคำนวณต่อ

<CodeExample example={examples['python101-functions-04']} />
`add(3, 4)` ส่ง `7` กลับมา แล้ว `7` ถูกเก็บไว้ใน `result` ก่อนนำไป `print()`

ความต่างระหว่าง `print()` กับ `return` ที่มือใหม่สับสนบ่อย: `print()` แค่แสดงค่าบนหน้าจอ ส่วน `return` ส่งค่ากลับมาให้โปรแกรมใช้ต่อได้

## ค่าเริ่มต้นของพารามิเตอร์ (Default arguments)

default argument คือค่าที่ function ใช้แทนเมื่อเราไม่ได้ส่งค่าเข้ามา

<CodeExample example={examples['python101-functions-05']} />
เรียก `greet()` เปล่า ๆ จึงได้ `Hello friend` ส่วน `greet("Anan")` ได้ชื่อที่เราส่งไป

## ขอบเขตของตัวแปร (Scope)

ตัวแปรที่สร้างข้างใน function มีอยู่แค่ใน function นั้น ถ้าเรียกใช้จากนอก function จะเกิด error เพราะข้างนอกมองไม่เห็นตัวแปรนั้น

<CodeExample example={examples['python101-functions-07']} />
ผลลัพธ์: `16` เพราะ `print(age)` อยู่ข้างใน function เดียวกับที่สร้าง `age`

## ข้อผิดพลาดที่พบบ่อย

- สร้าง function แล้วลืมเรียกใช้
- ใช้ `print()` แทน `return` ในงานที่ต้องเอาค่าไปคำนวณต่อ
- ตั้งชื่อ function ไม่บอกว่ามันทำอะไร

## สรุป

function ทำให้โค้ดเป็นระเบียบและไม่ต้องเขียนซ้ำ ใช้ parameter รับค่าเข้า ใช้ `return` ส่งผลออก โปรแกรมยิ่งใหญ่ยิ่งต้องแบ่งงานเป็น function
