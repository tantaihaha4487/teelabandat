อ่านบทเรียนอย่างเดียวยังไม่ทำให้เขียนโปรแกรมเป็น ต้องลงมือทำของที่ใช้งานได้จริงด้วย เลือกทำทีละโปรเจกต์ พอทำได้แล้วลองเพิ่มความสามารถเองอีกนิด

## 1. เกมทายเลข

เป้าหมาย: ให้คอมพิวเตอร์สุ่มเลข แล้วผู้ใช้ทายจนถูก

ได้ฝึก: `random`, loop, condition, input, error handling

ถ้าทำได้แล้ว ลองจำกัดจำนวนครั้ง เพิ่มระดับความยาก หรือเก็บคะแนนดีที่สุดไว้ในไฟล์

## 2. Calculator

เป้าหมาย: รับเลขสองตัวกับเครื่องหมาย แล้วคำนวณผลลัพธ์

<CodeExample example={examples['python101-projects-02']} />
`calculate()` ใช้ `return` ออกทันทีเมื่อเจอเครื่องหมายที่ตรง จึงไม่ต้องใช้ `elif` ถ้าไม่ตรงเลยสักตัว จะถึงบรรทัดสุดท้ายที่ตอบว่าไม่รู้จักเครื่องหมาย

## 3. To-do list

เป้าหมาย: เพิ่มงานและแสดงรายการงาน

ได้ฝึก: list, loop, function, file

ขั้นต่อไป: บันทึกงานลง `todo.txt` แล้วโหลดกลับมาตอนเปิดโปรแกรม

## 4. Password generator

เป้าหมาย: สุ่มรหัสผ่านตามความยาวที่ผู้ใช้กำหนด

ได้ฝึก: `random`, string, loop

## 5. Rock paper scissors

เป้าหมาย: เล่นเป่ายิ้งฉุบกับคอมพิวเตอร์

ได้ฝึก: condition, การสุ่มด้วย `random.choice()`, ตัวนับคะแนน

## 6. Contact book

เป้าหมาย: เพิ่ม ค้นหา และลบเบอร์ติดต่อ

ได้ฝึก: dictionary, loop, file

## 7. Quiz app

เป้าหมาย: ถามคำถามหลายข้อ ตรวจคำตอบ แล้วสรุปคะแนน

ได้ฝึก: list ที่เก็บ dictionary หลายตัว, loop, condition

## วิธีทำโปรเจกต์ให้ได้ผล

1. ทำเวอร์ชันที่เล็กที่สุดที่ใช้งานได้ก่อน
2. ทดสอบทุกครั้งที่เพิ่มความสามารถใหม่
3. ถ้าเจอ error ให้อ่านบรรทัดที่ error ชี้ก่อน
4. จดสิ่งที่อยากเพิ่มไว้ แล้วทำทีละข้อ

## สรุป

ทำครบทุกโปรเจกต์นี้แล้ว คุณจะได้ใช้พื้นฐานเกือบทุกเรื่องในคอร์ส ตั้งแต่ input, condition, loop, function, data structure, file ไปจนถึง error handling
