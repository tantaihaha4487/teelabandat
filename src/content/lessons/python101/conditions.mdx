Python ตรวจเงื่อนไขจากบนลงล่าง พอเจอข้อแรกที่เป็นจริงก็ทำตามข้อนั้นแล้วข้ามข้อที่เหลือทั้งหมด คะแนน 90 จึงได้ "ดีมาก" อย่างเดียว ไม่ได้ "ผ่าน" ด้วย ทั้งที่ 90 ก็มากกว่า 50

## ตัวดำเนินการเปรียบเทียบ

ตัวดำเนินการเหล่านี้เปรียบเทียบค่าสองค่า แล้วให้ผลเป็น `True` หรือ `False`

| เครื่องหมาย | ความหมาย |
| --- | --- |
| `==` | เท่ากับ |
| `!=` | ไม่เท่ากับ |
| `>` | มากกว่า |
| `<` | น้อยกว่า |
| `>=` | มากกว่าหรือเท่ากับ |
| `<=` | น้อยกว่าหรือเท่ากับ |

## นิพจน์ที่ให้ค่าจริงหรือเท็จ (Boolean expression)

เงื่อนไขที่ดีควรอ่านออกเสียงเป็นประโยคได้ เช่น `age >= 18` อ่านว่า "อายุอย่างน้อย 18" ถ้าอ่านเงื่อนไขของตัวเองแล้วยังงง ลองตั้งชื่อตัวแปรให้ชัดขึ้น

## ข้อผิดพลาดที่พบบ่อย

- ใช้ `=` (กำหนดค่า) แทน `==` (เปรียบเทียบ)
- ลืม `:` ท้ายบรรทัด `if`
- ย่อหน้าไม่เท่ากันในเงื่อนไขเดียวกัน
- เรียงเงื่อนไขผิด เช่น ตรวจ `score >= 50` ก่อน `score >= 80` ทำให้ไม่มีใครได้ "ดีมาก" เลย

## แบบฝึกหัด

1. รับ `age` แล้วแสดง `เด็ก` ถ้าน้อยกว่า 13, `วัยรุ่น` ถ้าน้อยกว่า 20, และ `ผู้ใหญ่` สำหรับกรณีที่เหลือ
2. รับ `score` แล้วแสดงเกรด A/B/C/D/F โดยใช้ช่วงคะแนน 80, 70, 60, 50 และต่ำกว่า 50
3. รับ `username` และ `password`; ให้เข้าสู่ระบบได้เฉพาะเมื่อ username เป็น `admin` และ password เป็น `1234`
