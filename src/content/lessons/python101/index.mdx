ยินดีต้อนรับสู่คอร์ส Python ภาษาไทยสำหรับผู้เริ่มต้นของ Python101 คอร์สนี้ออกแบบมาสำหรับคนที่เริ่มจากศูนย์ ไม่จำเป็นต้องเคยเขียนโปรแกรมมาก่อน เป้าหมายคือให้คุณอ่านโค้ด Python ออก เขียนโปรแกรมเล็ก ๆ ได้ และมีพื้นฐานพร้อมต่อยอดไปทำเว็บ วิเคราะห์ข้อมูล หรือระบบอัตโนมัติ

## วิธีเรียน

1. อ่านคำอธิบายให้เข้าใจก่อนคัดลอกโค้ด
2. พิมพ์โค้ดเองอย่างน้อยหนึ่งรอบ
3. ลองเปลี่ยนค่าตัวแปรและดูผลลัพธ์
4. ทำแบบฝึกหัดท้ายบท
5. ถ้าเจอ error ให้อ่านข้อความ error ก่อนค้นหาคำตอบ

## เริ่มจากตรงไหน

- [Setup](/learn/python101/setup/) ติดตั้ง Python และรันไฟล์แรก
- [Basics](/learn/python101/basics/) เรียนตัวแปร ชนิดข้อมูล และ output
- [Roadmap](/learn/python101/roadmap/) ดูภาพรวมการเรียน 4 สัปดาห์
- [Projects](/learn/python101/projects/) ฝึกทำโปรเจกต์จริง

## สิ่งที่จะได้เรียน

- ติดตั้ง Python และรันไฟล์ `.py`
- ตัวแปร ชนิดข้อมูล และการแสดงผล
- รับข้อมูลจากผู้ใช้และแปลงชนิดข้อมูล
- เงื่อนไข ลูป และโครงสร้างข้อมูล
- ฟังก์ชัน ไฟล์ error handling และ modules
- พื้นฐาน OOP และโปรเจกต์สำหรับผู้เริ่มต้น
