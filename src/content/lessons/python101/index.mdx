## สิ่งที่จะได้เรียน

- ติดตั้ง Python และรันไฟล์ `.py`
- ตัวแปร ชนิดข้อมูล และการแสดงผล
- รับข้อมูลจากผู้ใช้และแปลงชนิดข้อมูล
- เงื่อนไข ลูป และโครงสร้างข้อมูล
- ฟังก์ชัน ไฟล์ การจัดการ error และ modules
- พื้นฐาน OOP และโปรเจกต์สำหรับผู้เริ่มต้น

## เส้นทางแนะนำ

เริ่มที่ [ติดตั้งเครื่องมือ](/learn/python101/setup/) แล้วเรียนไปตามลำดับในรายการบทเรียน ถ้ามีพื้นอยู่แล้วจะข้ามไปบทที่สนใจก็ได้ แต่ถ้าเพิ่งเริ่ม แนะนำให้เรียงตามลำดับ เพราะแต่ละบทใช้ของที่เรียนจากบทก่อนหน้า
