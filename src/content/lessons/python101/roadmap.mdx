## สัปดาห์ที่ 1: เริ่มเขียนโค้ด

- ติดตั้ง Python และ editor
- รันไฟล์ `.py`
- ตัวแปร ข้อความ ตัวเลข และค่าจริง/เท็จ (variables, strings, numbers, booleans)
- ฝึก `print()` และ `input()`

เป้าหมาย: เขียนโปรแกรมที่รับข้อมูลแล้วแสดงผลได้

## สัปดาห์ที่ 2: ควบคุมการทำงาน

- เงื่อนไข `if/elif/else`
- loop `for` และ `while`
- list และ dictionary

เป้าหมาย: เขียนเกมทายเลข และโปรแกรมเก็บรายการง่าย ๆ ได้

## สัปดาห์ที่ 3: เขียนโค้ดให้เป็นระบบ

- functions
- files
- error handling
- modules

เป้าหมาย: เขียน todo app ที่บันทึกลงไฟล์ได้ และไม่พังง่าย ๆ เมื่อผู้ใช้กรอกผิด

## สัปดาห์ที่ 4: ต่อโปรเจกต์จริง

- OOP พื้นฐาน
- ทำโปรเจกต์ 2-3 ชิ้น
- อ่าน docs และค้นหาวิธีแก้ error เอง
- เริ่มใช้ virtual environment และ pip

เป้าหมาย: มีโปรเจกต์ระดับเริ่มต้นไว้ใส่ portfolio อย่างน้อย 2 ชิ้น

## หลังจบ Python101

เลือกทางที่สนใจ จะลองหลายทางก็ได้:

- Web: Flask, FastAPI, Django
- Data: pandas, matplotlib, Jupyter
- Automation: pathlib, requests, scheduling
- AI: numpy, scikit-learn, PyTorch พื้นฐาน

## Checklist

ถ้าทำข้อเหล่านี้ได้ทั้งหมด แสดงว่าพื้นฐานพร้อมไปต่อแล้ว

- อธิบายตัวแปรและชนิดข้อมูลได้
- ใช้ condition และ loop ได้
- ใช้ list/dictionary ได้
- เขียน function ได้
- อ่านเขียนไฟล์ได้
- จัดการ error พื้นฐานได้
- ทำโปรเจกต์เล็ก ๆ ได้ด้วยตัวเอง
