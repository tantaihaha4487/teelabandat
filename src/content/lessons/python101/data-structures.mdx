ตัวแปรหนึ่งตัวเก็บได้ทีละค่า แต่ข้อมูลจริงมักมาเป็นชุด เช่น คะแนนทั้งห้อง หรือข้อมูลนักเรียนหนึ่งคน โครงสร้างข้อมูล (data structure) คือวิธีเก็บหลายค่าไว้ด้วยกัน ใน Python ที่ใช้บ่อยมีสี่แบบ คือ list, tuple, dictionary และ set

## List

List เก็บค่าเรียงตามลำดับ และแก้ไขได้ เหมาะกับรายการที่ต้องเพิ่ม ลบ หรือเปลี่ยนค่าไปเรื่อย ๆ เขียนด้วยวงเล็บเหลี่ยม `[]`

<CodeExample example={examples['python101-data-structures-01']} />
`append()` เพิ่มค่าต่อท้าย `scores[0]` ดึงค่าตัวแรก และ `len()` บอกว่ามีกี่ค่า

## Tuple

Tuple คล้าย list แต่สร้างแล้วแก้ไม่ได้ เขียนด้วยวงเล็บ `()` เหมาะกับข้อมูลที่ไม่ควรเปลี่ยน เช่น พิกัด หรือค่าคงที่

<CodeExample example={examples['python101-data-structures-03']} />
ผลลัพธ์คือ `10` เพราะตำแหน่ง (index) ใน Python เริ่มนับจาก 0 ไม่ใช่ 1

## Dictionary

Dictionary เก็บข้อมูลเป็นคู่ key กับ value เขียนด้วยวงเล็บปีกกา `{}` ใช้เมื่ออยากเรียกข้อมูลด้วยชื่อ เช่น `student["name"]` แทนการจำว่าอยู่ตำแหน่งที่เท่าไร

<CodeExample example={examples['python101-data-structures-04']} />
บรรทัด `student["age"] = 17` เปลี่ยนค่าของ key ที่มีอยู่แล้ว ถ้า key นั้นยังไม่มี Python จะเพิ่มให้ใหม่

## Set

Set เก็บแต่ค่าที่ไม่ซ้ำ และไม่สนใจลำดับ เหมาะกับการตัดค่าซ้ำออก

<CodeExample example={examples['python101-data-structures-06']} />
`"python"` ใส่ไปสองครั้ง แต่ set เก็บไว้ครั้งเดียว และเพราะ set ไม่มีลำดับ ลำดับที่แสดงอาจไม่เหมือนกันทุกครั้งที่รัน

## Slicing

slicing คือการตัดเอาบางช่วงของ list ออกมา ตารางนี้แสดงตำแหน่งของแต่ละค่าใน `numbers`

| ค่า | `10` | `20` | `30` | `40` | `50` |
| --- | --- | --- | --- | --- | --- |
| index นับจากหน้า | 0 | 1 | 2 | 3 | 4 |
| index นับจากท้าย | -5 | -4 | -3 | -2 | -1 |

<CodeExample example={examples['python101-data-structures-08']} />
`numbers[1:4]` เริ่มที่ index 1 แล้วหยุดก่อน index 4 จึงได้ค่าที่ตำแหน่ง 1, 2 และ 3 ถ้าเว้นตัวหน้าอย่าง `[:3]` จะเริ่มจากต้น list ส่วน `[-1]` คือค่าตัวสุดท้าย

## เลือกใช้อะไรดี

| ต้องการ | ใช้ |
| --- | --- |
| รายการที่แก้ไขได้ | list |
| ค่าคงที่เป็นชุด | tuple |
| ข้อมูลมีชื่อกำกับ | dictionary |
| ข้อมูลไม่ซ้ำ | set |

## สรุป

เลือกโครงสร้างข้อมูลตามลักษณะของข้อมูล: เป็นรายการใช้ list, ไม่ควรเปลี่ยนใช้ tuple, มีชื่อกำกับใช้ dictionary, ไม่อยากให้ซ้ำใช้ set โปรเจกต์จริงแทบทุกตัวใช้อย่างน้อยหนึ่งในสี่แบบนี้
