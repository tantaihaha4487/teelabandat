OOP (Object-Oriented Programming) คือวิธีจัดโค้ดโดยรวมข้อมูลกับการกระทำที่เกี่ยวกับข้อมูลนั้นไว้ด้วยกันเป็น object

ลองนึกถึงนักเรียนหนึ่งคน เขามีข้อมูลคือชื่อกับคะแนน และมีสิ่งที่ทำได้ คือแสดงข้อมูลตัวเองและบอกว่าสอบผ่านหรือเปล่า object หนึ่งตัวก็เก็บทั้งสองอย่างนี้ไว้ในที่เดียว

## Class และ Object

class คือแบบพิมพ์เขียว ส่วน object คือของจริงที่สร้างจากแบบนั้น เหมือนแม่พิมพ์ขนมหนึ่งอันที่ใช้ทำขนมได้หลายชิ้น ขนมแต่ละชิ้นใส่ไส้ต่างกันได้

| คำ | ความหมาย | ตัวอย่าง |
| --- | --- | --- |
| Class | แบบพิมพ์เขียว | `Student` |
| Object | ของจริงที่สร้างจาก class | `mali`, `anan` |
| Attribute | ข้อมูลของ object | `name`, `score` |
| Method | สิ่งที่ object ทำได้ | `show_info()` |

## __init__

`__init__` เป็น method พิเศษที่ทำงานเองทันทีตอนสร้าง object ใช้ตั้งค่าเริ่มต้นให้ object

<CodeExample example={examples['python101-oop-02']} />
บรรทัดนี้ส่งค่าเข้า `__init__` แบบนี้:

| ค่าที่ส่งเข้าไป | parameter ที่รับ | เก็บไว้ใน object |
| --- | --- | --- |
| `"Mali"` | `name` | `self.name` |
| `90` | `score` | `self.score` |

`mali.name` จึงได้ `"Mali"` และ `mali.score` ได้ `90`

## ควรใช้ OOP เมื่อไร

ใช้ OOP เมื่อมีของชนิดเดียวกันหลายชิ้น และแต่ละชิ้นมีข้อมูลและพฤติกรรมของตัวเอง เช่น นักเรียนหลายคน บัญชีธนาคารหลายบัญชี สินค้าหลายชิ้น ตัวละครในเกม หรืองานหลายงานใน todo app

ถ้าโปรแกรมแค่คำนวณค่าเดียวแล้วจบ function ธรรมดามักอ่านง่ายกว่า class

## ข้อผิดพลาดที่พบบ่อย

- ลืมใส่ `self` เป็น parameter แรกของ method
- สร้าง object โดยไม่ส่งค่าที่ `__init__` ต้องการ
- ใช้ class ทั้งที่ function ธรรมดาก็พอ

## สรุป

OOP รวมข้อมูลกับการกระทำของมันไว้ด้วยกันใน object เหมาะกับโปรแกรมที่มีของชนิดเดียวกันหลายชิ้น แต่ถ้า function ธรรมดาอ่านง่ายกว่า ก็ไม่จำเป็นต้องใช้ class
